# 3D Dynamic Actions

3D Dynamic Actions is a Minecraft Bedrock resource pack that combines expressive animations inspired by Action and Stuff, 3D skin layers inspired by Skin Layers 3D, and dynamic eyes inspired by Eyes Dynamic. This pack enhances the visual and interactive experience of Minecraft Bedrock by adding realistic and engaging animations to player characters.

## Install

1. Download the resource pack from the GitHub repository.
2. Open Minecraft Bedrock Edition.
3. Go to the "Settings" menu.
4. Select "Resource Packs" from the left-hand menu.
5. Click on the "Add Resource Pack" button.
6. Navigate to the downloaded resource pack and select it.
7. Ensure the resource pack is enabled by toggling the switch next to it.
8. Start a new world or reload the current world to apply the resource pack.

## Use

1. Launch Minecraft Bedrock Edition.
2. Start a new world or load an existing one.
3. The animations will automatically apply to player characters.
4. Observe the expressive and fluid animations as you interact with the game world.
